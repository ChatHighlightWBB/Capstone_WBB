## 📌 1. 프로젝트 개요 (Overview)
**와바바(WBB)**는 장시간 진행되는 인터넷 라이브 방송(유튜브, 치지직, SOOP TV 등)에서 시청자 실시간 반응(채팅 감정, 채팅 화력)과 오디오/비주얼 데이터를 융합 분석하여 핵심 재미 구간을 자동으로 추출하고 요약 영상을 제공하는 웹 서비스입니다.

기존의 단순 음량(dB) 기반 하이라이트 추출 한계를 극복하기 위해, **PP-OCRv3 텍스트 인식**과 **KoBERT 한국어 감정 분석**, **Whisper STT**를 결합한 **2단계 정제 멀티모달 아키텍처**를 채택했습니다.
