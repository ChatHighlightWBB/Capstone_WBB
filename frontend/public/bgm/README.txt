와바바 배경음악 넣는 곳
=======================

이 폴더에 아래 이름 그대로 음원 파일을 넣으면 배경음악으로 반복 재생됩니다.

파일 이름       나오는 화면
-------------  ------------------------------------------------
main.mp3       입장 페이지("와바바 바로가기"를 누른 뒤) · 메인 화면
analyze.mp3    분석 중 화면
(결과 화면)    배경음악 없음 — 점수 공개 효과음만 나옴

- 파일 이름(main.mp3, analyze.mp3)과 확장자를 꼭 맞춰 주세요.
  다른 이름이나 형식(.wav 등)을 쓰려면 src/sound.js 맨 위의 TRACKS를 고치면 됩니다.
- 곡이 바뀔 때는 앞 곡이 작아지면서 다음 곡이 커지도록 자연스럽게 넘어갑니다.
- 곡은 끝나면 처음부터 계속 반복되고, 다른 화면에 갔다 돌아오면 멈췄던 곳부터 이어서 나와요.
- 음량은 화면의 스피커 버튼(소리 설정)에서 조절해요. 처음 기본값은 배경음악 45%, 효과음 70%예요.
- 파일이 없으면 그 화면은 조용히 넘어가고, 브라우저 개발자 도구 콘솔에 안내 문구가 뜹니다.
- 저작권이 있는 곡은 사용 허락(라이선스)을 꼭 확인하세요.
